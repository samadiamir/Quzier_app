# 🧠 Quzier App

A modern Python quiz application that fetches True/False questions from an online API and displays them through a custom graphical user interface built with CustomTkinter.

## Features

- Fetches quiz questions dynamically from an API
- True / False gameplay
- Modern GUI using CustomTkinter
- Object-Oriented Programming (OOP) architecture
- Score tracking system
- Clean and maintainable code structure

## Technologies Used

- Python
- CustomTkinter
- Requests
- OOP Design Principles
